# Multiplayer Security Doors Expanded Patch

A RimWorld multiplayer compatibility patch for [Security Doors Expanded](https://steamcommunity.com/sharedfiles/filedetails/?id=3777106218).

This mod uses RimWorld Multiplayer to synchronize Security Doors Expanded-related data and behavior between multiplayer clients.

## Features

- Adds multiplayer support for Security Doors Expanded.

## Requirements

- RimWorld
- Harmony
- RimWorld Multiplayer
  - [GitHub version](https://github.com/rwmt/Multiplayer) or [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=2606448745) version
- [Security Doors Expanded](https://steamcommunity.com/sharedfiles/filedetails/?id=3777106218)

## Installation

### Steam Workshop

Subscribe to the required mods and add them to your RimWorld mod list in the following order:

1. Harmony
2. Core
3. Royalty, Ideology, Biotech, and Anomaly, if applicable
4. Multiplayer
5. Security Doors Expanded
6. [Multiplayer Security Doors Expanded Patch](https://github.com/Keullaeseu/Multiplayer-Security-Doors-Expanded-Patch/releases/latest)

The patch should load after both RimWorld Multiplayer and Security Doors Expanded.

### Manual Installation

1. Download the latest release from the [**Releases**](https://github.com/Keullaeseu/Multiplayer-Security-Doors-Expanded-Patch/releases/latest) section.
2. Extract the mod folder into your RimWorld `Mods` directory.
3. Enable the required mods in the RimWorld.
4. Use the recommended load order listed above.
5. Make sure every multiplayer player has the same mod list, configuration, and load order.

## Multiplayer Usage

All players should have the following mods installed and enabled:

- RimWorld Multiplayer
- Security Doors Expanded
- Multiplayer Security Doors Expanded Patch

The host and all connected clients must use compatible versions of:

- RimWorld
- RimWorld Multiplayer
- Security Doors Expanded
- Multiplayer Security Doors Expanded Patch

For the best results, every player should use the same game version, mod versions, configuration files, and load order.

## Compatibility

This mod is intended to provide multiplayer compatibility for Security Doors Expanded.

It does not replace:

- RimWorld Multiplayer
- Security Doors Expanded

Compatibility may be affected by other mods that modify security doors, door controls, power behavior, vacuum systems, or related building functionality.

## Known Limitations

- Compatibility may be affected by future updates to RimWorld Multiplayer or Security Doors Expanded.
- Other mods that alter Security Doors Expanded may require additional compatibility work.
